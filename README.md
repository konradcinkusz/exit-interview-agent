# exit-interview-agent

Open-source AI agent for structured exit interviews with former employees. Bring your own
model: use it via MCP from your own AI client, or run the CLI with your API key or a local
model. Privacy-preserving employer signals and an eval harness scoring interview quality from
OpenTelemetry traces.

> Status: bootstrapping. This `main` holds only the licence and this note; the project is
> being built in small pull requests following
> [`konradcinkusz/architecture-standards`](https://github.com/konradcinkusz/architecture-standards).
